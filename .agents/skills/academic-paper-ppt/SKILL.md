# 学术论文分享 PPT

让听众顺着一个科学问题理解论文。页面放结论与证据，备注讲清从问题到结论的推理，并给关键追问留出处。

## 确定范围

凡新制作、重排或交付学术汇报，先读 [人工反馈与验收约束](references/review-requirements.md)。仅有论文和这份规范时，也按其中的排版、数值、图表与放映检查执行。

1. 先读用户的时长、听众、主讲论文、现有模板和明确不许改的部分。没有时长时，可以按 8–12 分钟单篇组会起稿，并说明假设。局部改稿直接定位页码、页面对象和备注，保留其他页、备注、页序及已有可编辑对象。
2. 以用户指定的论文版本为准。读摘要和引言定问题，读方法与图注校验流程，读主实验、消融和讨论定证据边界，再按需要查补充材料或实现。对每项核心事实留论文版本、Fig.／Table／Eq.／§及来源。分别核对论文作者和机构、发表状态、汇报人和机构，匿名投稿按匿名处理。
3. 按 [内容与证据](references/content-and-evidence.md) 选材。优先排出科学问题、数据与处理、总流程、主要方法、必要细节、实验结果、discussion 与方法对比。短讲可合页，非实证论文按证明或论证结构调整。多论文分享给主线工作更多篇幅，辅助工作讲清一个功能或区别即可。

## 从提纲做成可讲的页面

先规划全稿的内容分组与顺序，再制作页面。第二页固定为「目录」，用简短、具体的章节名预告实际讲述路线。按 [目录与章节导航](references/design-system.md#目录与章节导航) 根据条目数量、标题长度和信息层级选版式，定稿后核对目录与正文的对应关系。

- 先为每页写一句听众应该记住的判断，从正文、Methods、附录和补充材料优先挑出支撑判断的原图或原表。按 [内容与证据](references/content-and-evidence.md#先筛选上屏内容) 把旁支、推导和次要参数放进备注或附录，之后才排版。只有几行字的内容页先复核独立任务和图证，优先把同一板块中可共用图证的小节合并，或把次要细节放进备注。
- 按 [视觉规范与硬约束](references/layout-specification.md) 选页型并验收，按 [设计体系](references/design-system.md) 试排普通文字页、方法原图页和结果页。重新设计版面时，先用代表性的正文页验证原图、说明和结论的阅读关系，再铺开全稿。普通内页用白底、近黑正文和清晰可见的北大红页眉锚点，与封面风格呼应。左上放短标题，底部放简洁的来源脚注。自排标题、图注及正文写成完整短语或句子，省去用中点连接的文字片段。有用的小标题放在标题下并以细线分隔，可以用来交代对象、条件或证据。正文围绕主证据排布，封面用独立构图，中央图文区通用白底，用封面边缘和标题层级增加北大红的分量。参考用户提供的版式时，复用其配色分工、导航层级和图文关系，并按当前原图与内容密度调整。
- 默认白底，所有自行排版的可读文字用近黑或高对比度深色，重点用北大红（RGB 139, 0, 18，PPT 色值 `#8B0012`）。标题、正文、图注、图内自制标签、脚注和表格文字均避免浅灰及其他浅色。中性浅灰用于底色和分隔线。按 [颜色角色](references/design-system.md#按角色分配颜色) 核对封面、内页、表头与模板母版，去除玫瑰色或粉灰衬底。
- 全稿不显示幻灯片页码或总页数，模板自带的页码对象也须移除。按原文保留来源脚注、图表编号和参考文献编号。
- 幻灯片中所有自行排版的中文一律用宋体（SimSun），英文和拉丁数字用 Arial。按 [字体设置](references/cover-and-visuals.md#配色和文字排版) 核对混排与导出结果。
- 正文默认用一组紧凑的原生项目符号。每条直接写谁做了什么、改变了什么、测到了什么，通常保留 2–4 条。可在行内加粗关键术语或数字。用统一悬挂缩进和字号，普通同级分点用段距组织。图旁确需逐项指向流程模块、原图分面或证据层级时，可用与图对应的短标题分组。按 [分点与图文排版](references/design-system.md#分点与图文排版) 根据主图比例选择上下或图文并列。
- 所有自行编写或改写的公式都先写成 LaTeX，再通过公式功能插为原生可编辑公式。独立公式和正文内的短公式都适用。少量补充公式放在相关方法、指标或结果页的一侧，贴近变量释义和读法。公式本身承担独立讲解任务时可单开一页，公式居左，解释居右，逐组对齐。按 [公式插入与目视检查](references/cover-and-visuals.md#公式插入与目视检查) 核对最终 PPTX。禁止用普通文本框、图片或矢量轮廓代替公式对象。
- 数据、方法和结果优先用论文原图，保留读图所需的坐标、单位、图例和分面编号。实验优先展示作者在主文明确解读或强调的结论所对应的原图、原表或分面。原图清楚时直接引用，保留其可核查信息。复杂主图可独占一页。引用图、表、关键结果或他人结论时，当页加可核查的来源脚注。多篇论文分享的最后一页为「参考文献」，用统一的学术格式逐条列出，按 [图表来源与参考文献](references/content-and-evidence.md#图表来源与参考文献) 核对。
- 按 [演讲者备注](references/speaker-notes.md) 写逐页口播，具体到技术动作和一张图怎么看。推导、替代解释和细枝末节可放备答或附录。只改备注的任务，仅写入备注，不重排或重导入正文对象。
- 用户指定 SVG → HTML → PPT、模板或特定方式时沿用其路径。一般交付采用带原生演讲者备注的可编辑 PPTX。按当前可用的专业工具完成制作，不因这套 Skill 另加固定格式要求。

## 交付前复核

- 按时长试读主线，确认核心结果和不足都有时间讲。每个术语在首次真正需要时讲明，每次转场都来自一个具体问题或关系。
- 逐页核对核心数字、分母、单位、评估子集、基线、小数位和图号。对结果页按「测法、读图、结论」口播一次，预印本、投稿、录用和正式发表各按原文标示。按 [交付检查](references/review-requirements.md#交付检查) 核对。
- 检查一页能否只读标题、主证据和第一条分点就说出核心判断。删去重复图注、图中文字或上页内容的分点，再查听众是否还能解释方法或读出对照。
- 按 [放映验收](references/cover-and-visuals.md#放映验收) 逐张用视觉能力查看最终 PPTX 的实际放映渲染，检查整页疏密和视觉重心。发现大框包短语、文字底色分组、同级分点错位或一页多种强调色时，先重排，再重新渲染检查。按 [交付检查](references/review-requirements.md#交付检查) 复核浅色文字和稀疏页。检查有无过长标题、无谓空白、并排的长篇文字、被拆成表格的句子，以及原图脚注和尾页参考文献是否齐全。核对裁切、分辨率、汉英混排、字号和备注绑定，确认各页均无页码。对所有含公式的页，逐条目视检查最终渲染后的公式并确认公式对象可编辑。发现塞不下时先删冗余、拆页或把细节放备注。
- 验证导出文件可打开、正文与备注可编辑。定向改稿时比较改前改后，确认用户指定的保留项。只改备注时检查幻灯片 XML 或页面渲染一致，并回读目标页备注。按用户指定的交付方式保存，同步说明任何仍影响使用的缺项。
