# 学术论文分享 PPT

让听众顺着一个科学问题理解论文。页面放结论与证据，备注讲清从问题到结论的推理，并给关键追问留出处。版式不靠感觉：所有坐标、字号、图幅和留白都有数值，做完逐项量。

## 先读哪份

| 任务 | 必读 |
|---|---|
| 任何新制或重排 | [版面规格](references/layout-specification.md) → [页面配方](references/page-recipes.md) → [封面、图像与公式](references/cover-and-visuals.md) → [验收清单](references/review-requirements.md) |
| 定选材与每页讲什么 | [内容与证据](references/content-and-evidence.md) |
| 目录、参考文献、配色 | [设计体系](references/design-system.md) |
| 写备注 | [演讲者备注](references/speaker-notes.md) |
| 只改局部 | 对应文件 + 验收清单第 2、6 步；不改用户未授权的页 |

数值只认 [版面规格](references/layout-specification.md)，其他文件不另立标准。两份参考稿《Lean Retrieval》《ProteinMPNN》的参数已量入规格，不需要原文件在手。

## 制作流程

按顺序做，每步有门禁；门禁不过不进入下一步。

1. **定范围**：时长、听众、篇数、指定模板、不可改部分。缺失时按 8–12 分钟单篇起稿并写明假设。读摘要和引言定问题，读方法与图注校验流程，读主实验、消融和讨论定边界。
2. **写论证链**：一句话写清「已有方法能做什么 → 什么问题卡着 → 论文改了哪一步 → 什么证据支持」。按 [内容与证据](references/content-and-evidence.md) 生成页面清单（听众要懂什么 / 证据 / 口播要点 / 出处）。
3. **选证据**：每页先定一句判断，再挑支撑它的原图、原表或公式。图从 PDF 抽出后**按墨迹紧裁**再量尺寸；记录 Fig./Table/Eq./§。
4. **做三张样张**：封面、方法页、最密的结果页。按 [页面配方](references/page-recipes.md) 起排，按 [版面规格](references/layout-specification.md) 量内容上/下沿、图占页面积和空白。三张都达标再铺全稿。
5. **铺全稿**：固定页眉三带与字号阶梯；目录第二页；页型按配方选；内容页不留半页空白。
6. **写备注**：按 [演讲者备注](references/speaker-notes.md) 的四段结构，逐页 40–200 字，复杂页加备答与出处；写完朗读计时。
7. **渲染复核**：导出最终 PPTX → 转 PDF → 逐页转图，按 [验收清单](references/review-requirements.md) 走完；公式与备注从最终文件回读。

## 十条不可协商

1. **画布与三带**：16:9；内容带 1.95–6.40 英寸；页脚线 6.62；页底 0.3 英寸内无对象。
2. **页面要满**：含图页下沿 ≥5.90，纯文字页 ≥5.20；不得出现 >1.2×1.2 英寸的无对象空洞；只有一两行字的页合并。
3. **图要够大**：单图页图墨迹 ≥32% 页面积、高 ≥3.6 英寸；图必须是页面最大对象；PDF 图先紧裁白边。
4. **字号阶梯**：标题 32 pt；分点 17 pt；图注 13 pt；脚注 12 pt；正文不低于 17 pt，塞不下就删内容或拆页。
5. **红色一处**：北大红 `#8B0012` 只用于章节定位、一个关键数字或结论；页眉之外同页不出现第二处强红。
6. **标题写判断**：不写「XX 的读法」「结果分析」「小结」；起不出具体标题就省略标题行。分点全部无标签，模块名、面板号写进句内。
7. **公式原生**：所有自排公式先写 LaTeX，再转为可编辑 Office Math；每个公式三层解释（算什么、符号、方向）；一页 ≤3 式。
8. **目录具体**：第二页，3–8 项，条目名点出科学内容（非「研究背景/方法介绍」），与正文同名同序；不写描述行和页码范围。
9. **封面有上下**：顶带一个信息锚点（kicker/校徽 + 细线），底带放汇报人、日期、机构/图源；主图 ≥15% 页面积。
10. **末页有信息**：总结页（三条结论 + 一条边界）或参考文献页；不设单独 `Thank you` 页；多篇分享末页必须是参考文献。

## 常见任务

- **局部改稿**：先定位页码、对象和备注；只动用户指定范围；改完给同页改前/改后对照。
- **多论文分享**：主线工作篇幅最大；目录用双列并带代表工作名；末页参考文献按首次引用编号；比较只在同口径下进行。
- **只有论文、没有素材**：先查正文、Methods、附录和补充材料；仍缺图时用原生形状画示意并标「汇报示意」，不为凑图生成假数据。
- **公式页**：只给真正承担讲解任务的式子单独开页；其余贴在方法或结果页一侧，变量释义就近。
- **用户指定模板/颜色**：整套替换色值与母版，但保留三带、字号阶梯、图幅和留白指标。

## 交付

交付带原生备注的可编辑 PPTX。渲染后的逐页图用于复核，不替代 PPTX。交付说明写清：页数、时长、主要证据页、仍存在的缺项（如无法核验的公式或外链）。分析类任务给结论（判断 + 依据 + 风险 + 下一步），不堆材料。
