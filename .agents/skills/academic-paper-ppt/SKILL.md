# 学术论文分享 PPT

让听众顺着一个科学问题理解论文。页面放结论与证据，备注讲清从问题到结论的推理，并给关键追问留出处。

## 确定范围

1. 先读用户的时长、听众、主讲论文、现有模板和明确不许改的部分。没有时长时，可以按 8–12 分钟单篇组会起稿，并说明假设。局部改稿直接定位页码、页面对象和备注，保留其他页、备注、页序及已有可编辑对象。
2. 以用户指定的论文版本为准。读摘要和引言定问题，读方法与图注校验流程，读主实验、消融和讨论定证据边界，再按需要查补充材料或实现。对每项核心事实留论文版本、Fig.／Table／Eq.／§及来源。分别核对论文作者和机构、发表状态、汇报人和机构，匿名投稿按匿名处理。
3. 按 [内容与证据](references/content-and-evidence.md) 选材。优先排出科学问题、数据与处理、总流程、主要方法、必要细节、实验结果、discussion 与方法对比。短讲可合页，非实证论文按证明或论证结构调整。多论文分享给主线工作更多篇幅，辅助工作讲清一个功能或区别即可。

## 从提纲做成可讲的页面

- 逐页先写一句可由本页证据支持的结论或问题，再决定正文、图和备注各承担什么。方法页说清输入、由谁做什么、输出是什么。结果页说清比较对象、指标方向、数字和适用范围。
- 先完成封面及代表性的方法页和结果页。按 [封面与可视化](references/cover-and-visuals.md) 在红黑白、深绿白、蓝白中选一套全稿配色。用白底和近黑正文，强调色只用于重点词、关键数值和图表中的重点系列。用户明确指定模板或配色时沿用其要求。
- 全稿可编辑文字只用中文宋体（SimSun）和英文 Arial。中英混排按文字脚本分别指定字体，交付前按 [字体设置](references/cover-and-visuals.md#配色和文字排版) 核对导出结果。
- 正文用左对齐分点，同级项目起笔和续行对齐。普通标题、标签、数字和结论直接排在页面底色上，保持文字框无填充、无边框。用字重、字号、留白和细分隔线建立层级。避免用整块文字底色、结论横幅或围框区分内容，尤其是一两行短语占一大块的布局。
- 所有自行编写或改写的公式都先写成 LaTeX，再通过公式功能插为原生可编辑公式。独立公式和正文内的短公式都适用。按 [公式插入与目视检查](references/cover-and-visuals.md#公式插入与目视检查) 核对最终 PPTX。禁止用普通文本框、图片或矢量轮廓代替公式对象。
- 优先使用可核对的原论文图。按汇报需要选 panel，保留坐标、单位、图例和编号。流程示意、数据图与装饰图明确区分。用自绘或生成图解释概念时标注示意，实验结构和数据由原始证据支持。
- 按 [演讲者备注](references/speaker-notes.md) 写逐页口播，具体到技术动作和一张图怎么看。推导、替代解释和细枝末节可放备答或附录。只改备注的任务，仅写入备注，不重排或重导入正文对象。
- 用户指定 SVG → HTML → PPT、模板或特定方式时沿用其路径。一般交付采用带原生演讲者备注的可编辑 PPTX。按当前可用的专业工具完成制作，不因这套 Skill 另加固定格式要求。

## 交付前复核

- 按时长试读主线，确认核心结果和不足都有时间讲。每个术语在首次真正需要时讲明，每次转场都来自一个具体问题或关系。
- 对关键数字回查原表，确认分母、单位、评估子集、基线和小数位。核对推断的范围和每页的图号，区分预印本、投稿、录用和正式发表。
- 按 [放映验收](references/cover-and-visuals.md#放映验收) 逐页检查渲染。发现大框包短语、文字底色分组、同级分点错位或一页多种强调色时，先重排，再重新渲染检查。核对裁切、分辨率、汉英混排、页码、字号和备注绑定。对所有含公式的页，逐条目视检查最终渲染后的公式并确认公式对象可编辑。发现塞不下时先删冗余、拆页或把细节放备注。
- 验证导出文件可打开、正文与备注可编辑。定向改稿时比较改前改后，确认用户指定的保留项。只改备注时检查幻灯片 XML 或页面渲染一致，并回读目标页备注。按用户指定的交付方式保存，同步说明任何仍影响使用的缺项。
