# 学术论文分享 PPT

让听众顺着一个科学问题理解论文。页面放结论与证据，备注讲清从问题到结论的推理，并给关键追问留出处。

## 确定范围

凡新制作、重排或交付学术汇报，先读 [人工反馈与验收约束](references/review-requirements.md)。仅有论文和这份规范时，也按其中的排版、数值、图表与放映检查执行。

1. 先读用户的时长、听众、主讲论文、现有模板和明确不许改的部分。没有时长时，可以按 8–12 分钟单篇组会起稿，并说明假设。局部改稿直接定位页码、页面对象和备注，保留其他页、备注、页序及已有可编辑对象。
2. 以用户指定的论文版本为准。读摘要和引言定问题，读方法与图注校验流程，读主实验、消融和讨论定证据边界，再按需要查补充材料或实现。对每项核心事实留论文版本、Fig.／Table／Eq.／§及来源。分别核对论文作者和机构、发表状态、汇报人和机构，匿名投稿按匿名处理。
3. 按 [内容与证据](references/content-and-evidence.md) 选材。优先排出科学问题、数据与处理、总流程、主要方法、必要细节、实验结果、discussion 与方法对比。短讲可合页，非实证论文按证明或论证结构调整。多论文分享给主线工作更多篇幅，辅助工作讲清一个功能或区别即可。

## 从提纲做成可讲的页面

- 先为每页写一句听众应该记住的判断，选择最能支撑它的一幅图、一个对照或一组关键数字。按 [内容与证据](references/content-and-evidence.md#先筛选上屏内容) 把旁支、推导和次要参数放进备注或附录，之后才排版。数据、方法和实验是备选模块，可以按论证需要合页。
- 按 [设计体系](references/design-system.md) 试排普通文字页、方法原图页和结果页。普通内页用白底、左上短标题和简洁的来源脚注。有用的小标题放在标题下并以细线分隔，可以用来交代对象、条件或证据。正文围绕主证据排布，封面用独立构图。参考用户提供的版式时，复用适合此稿的分点层级和图文关系。
- 全稿不显示幻灯片页码或总页数，模板自带的页码对象也须移除。按原文保留来源脚注、图表编号和参考文献编号。
- 幻灯片中所有自行排版的中文一律用宋体（SimSun），英文和拉丁数字用 Arial。按 [字体设置](references/cover-and-visuals.md#配色和文字排版) 核对混排与导出结果。
- 正文默认用一组紧凑的原生项目符号。每条直接写谁做了什么、改变了什么、测到了什么，通常保留 2–4 条。可在行内加粗关键术语或数字。用统一悬挂缩进和字号，不给每条另设小标题、分隔线或卡片。按 [分点与图文排版](references/design-system.md#分点与图文排版) 根据主图比例选择上下或图文并列。
- 所有自行编写或改写的公式都先写成 LaTeX，再通过公式功能插为原生可编辑公式。独立公式和正文内的短公式都适用。按 [公式插入与目视检查](references/cover-and-visuals.md#公式插入与目视检查) 核对最终 PPTX。禁止用普通文本框、图片或矢量轮廓代替公式对象。
- 方法和结果优先用论文原图，保留读图所需的坐标、单位、图例和分面编号。复杂的主图或结果图可独占一页，充分使用版心。引用图、表、关键结果或他人结论时，当页加可核查的来源脚注。多篇论文分享的最后一页为「参考文献」，用统一的学术格式逐条列出，按 [图表来源与参考文献](references/content-and-evidence.md#图表来源与参考文献) 核对。
- 按 [演讲者备注](references/speaker-notes.md) 写逐页口播，具体到技术动作和一张图怎么看。推导、替代解释和细枝末节可放备答或附录。只改备注的任务，仅写入备注，不重排或重导入正文对象。
- 用户指定 SVG → HTML → PPT、模板或特定方式时沿用其路径。一般交付采用带原生演讲者备注的可编辑 PPTX。按当前可用的专业工具完成制作，不因这套 Skill 另加固定格式要求。

## 交付前复核

- 按时长试读主线，确认核心结果和不足都有时间讲。每个术语在首次真正需要时讲明，每次转场都来自一个具体问题或关系。
- 逐页核对核心数字、分母、单位、评估子集、基线、小数位和图号。对结果页按「测法、读图、结论」口播一次，预印本、投稿、录用和正式发表各按原文标示。按 [交付检查](references/review-requirements.md#交付检查) 核对。
- 检查一页能否只读标题、主证据和第一条分点就说出核心判断。删去重复图注、图中文字或上页内容的分点，再查听众是否还能解释方法或读出对照。
- 按 [放映验收](references/cover-and-visuals.md#放映验收) 逐页检查渲染。发现大框包短语、文字底色分组、同级分点错位或一页多种强调色时，先重排，再重新渲染检查。检查有无过长标题、无谓空白、并排的长篇文字、被拆成表格的句子，以及原图脚注和尾页参考文献是否齐全。核对裁切、分辨率、汉英混排、字号和备注绑定，确认各页均无页码。对所有含公式的页，逐条目视检查最终渲染后的公式并确认公式对象可编辑。发现塞不下时先删冗余、拆页或把细节放备注。
- 验证导出文件可打开、正文与备注可编辑。定向改稿时比较改前改后，确认用户指定的保留项。只改备注时检查幻灯片 XML 或页面渲染一致，并回读目标页备注。按用户指定的交付方式保存，同步说明任何仍影响使用的缺项。
