# 学术汇报设计体系

用稳定的网格建立秩序，用主图和阅读顺序区分不同页型。每页先确定听众看完应记住的一句话，再决定要看哪里、怎样从图读出这句话、出处放在哪里。标题可以是短语、短问句或短判断，完整结论可以落在图下或讲者备注里。

## 把美学原则变成版式决定

| 原则 | 页面上的做法 |
|---|---|
| 层级与尺度 | 用字号、字重和面积建立主次。证据页给原图最大的面积，标题和图互相指向。少量关键词或数字在完整句子里加粗或斜体。 |
| 对齐与重复 | 共享标题左线、图文版心、脚注区和页码位置。换章节可以调整构图，换背景母版时用同一套内容锚点。 |
| 邻近与分组 | 图注贴图，变量解释贴公式，相关分点间距小于组间距。先用距离、对齐和细线分组，普通文字框无填充、无边框。 |
| 对比 | 白地承载近黑正文与原图。全套默认一个强调色，用在有信息含义的位置。用实际字形、字重和对比度一起判断读距。 |
| 视觉平衡 | 按图像面积、颜色深浅和文字密度判断重量。水平居中以主图和正文组合为参照，正文仍左对齐。发现视觉重心偏移时，先挪整组或调整图幅。 |
| 留白 | 留在页边、章节之间和图注附近来建立阅读节奏。给密图腾空间时，先去掉重复解释、缩短标题、合并装饰区。 |

## 先定网格，再分配页型

1. 先在缩略规划里写明每页的任务、证据和阅读顺序，预留标题、图文与脚注。16:9 新稿的左右安全边距可从页宽的 5% 起步。内页的标题左线、标题文字高度和页脚位置一起锁定，内容在其间分配。直排正文从同一左线起笔，主图按比例放进版心。
2. 先试封面、含最多细节的方法页和最密的结果页。在 16:9、约 13.33 × 7.5 英寸版面上，可从单行内页标题 28–34 pt、正文 20–24 pt、图注和脚注 12–14 pt 试排，再按场地、图表密度和放映效果调整。全稿同级同字号。中文宋体（SimSun），英文和数字 Arial。
3. 先找主要证据，再匹配页型。两组内容只有确实需要并排对照时才使用双栏。图表与一两行解释可以在同一页上下排。复杂原图可以独占版心，图例太小就用独页、拆 panel 或删文字腾位置。图、公式和表格之间的选择由本页要回答的问题决定。

| 页型 | 内容顺序与适合的背景 |
|---|---|
| 封面 | 主标题、论文及汇报信息、可核对的单一主视觉。可用一个浅色色面区分标题与图像，构图按图像比例选。 |
| 科学问题与背景 | 短标题、原图或示意、图下的一到两条完整说明。沿用内页母版。 |
| 流程与方法 | 流程图、原图或原生公式为主体，变量释义靠近相关对象。运算多的页面以白底和纵向阅读为主。 |
| 结果 | 原图占主体，图下放一条结果或读图提示，脚注注明来源。复杂图独页时可以沿用普通内页的标题和页脚，并收起背景纹样。 |
| 更多讨论 | 图或一条观察与两三条左对齐讨论，标题可用「讨论」「更多讨论」或 `Discussion`。用短分点交代局限和开放问题。 |

## 按角色分配颜色

全稿选一套颜色。红黑白为默认。深绿白、蓝白也可按用户选择、机构色或原图色彩使用。主底用于内容，主题色用于重点字、数值与必要的线，浅色面用于较大的版面区块，线色只承担分隔。按用户指定的配色或母版时保留同样的角色分工。

| 方案 | 页面与图表底 | 正文、脚注 | 主题色 | 可选浅色面 | 可选分隔线 |
|---|---|---|---|---|---|
| 红黑白 | 白 `#FFFFFF` | 近黑 `#1A1A1A` | 深红 `#A32032` | `#F5E9E9` | `#E0D2D2` |
| 深绿白 | 白 `#FFFFFF` | 近黑 `#1A1A1A` | 深绿 `#164A3B` | `#EAF2ED` | `#D3E1D8` |
| 蓝白 | 白 `#FFFFFF` | 近黑 `#1A1A1A` | 深蓝 `#173B68` | `#EAF1F8` | `#D3DEE9` |

- 浅色色面和浅线用于衬底。正文、脚注和强调文字用近黑或主题深色。以普通文字对背景 4.5:1 作为选色时的对比参考，再按实际放映环境目视检查。
- 主题配色和图表的数据颜色各有用途。原图沿用原有配色、标记和图例。自绘图里无顺序类别用分类色，有序量值用顺序色，只有数据有明确中点（如零或基线）时才用发散配色。同一模型跨页颜色一致。关键系列同时用文字、线型或点形区分，检查灰度下也能辨认。

## 背景和章节变化

- 用封面和正文两种母版起稿，确有需要时再加变体。正文可以是纯白，也可以用边缘清晰的浅色色面，例如顶部浅色标题区配细页脚。面积要服务标题和图表，标题下缘与主图之间留出稳定的间距。
- 内容区较满时，把变化放到图的大小、排列和文字密度上。确需更强的章节变化时，选择一个纯色块或一处简单几何切角，保留共用标题、正文版心和页脚。背景图形放在母版或底层，检查它有没有把左侧标题和正文压低。不同页型的色面形状可以变化，底色、强调色和边界风格保持一致。
- 默认保留清晰的纯色边缘，色块过重时先降低它与白底的明度差、缩小面积或移到页边。避免上下同时用渐变、每页另换色面方向和为了补空白而添加色带。用户明确要求上下背景等高时，用同一母版的同一高度值并核对渲染图。用户选定版式优先，局部改稿保留既定比例。

## 全稿校验

1. 看连页缩略图。对比封面、普通内页、方法、结果和讨论页，确认读者能认出同一套模板。找出相邻两页跳动的标题与页脚、无内容支撑的大空白、压迫主体的色面，以及换背景后整体偏移的文字。
2. 看最终 PPTX 的放映尺寸。检查最长的一行标题、最小的图例与来源、最密的一页是否仍能读清。同级文字字号一致，图注靠近原图，重点能在完整句子或图中被找到。按 [公式插入与目视检查](cover-and-visuals.md#公式插入与目视检查) 逐式核对。
3. 局部变更背景时，拿改前和改后同一页并排核对内容位置、图幅与视觉重心。如果旧版或朴素版本读起来更顺，采用效果更好的版本。

## Proton-PottsMPNN 的版式取舍

这套八页短讲选用红黑白。保留原版清楚的浅色标题区、右上角斜切纹样和细页脚。封面由论文标题和结构图共同撑起，流程页把宽度留给原图，结果页用大图配图下解读，「更多讨论」用同一版心与左对齐分点收束。上下渐变让页面边缘同时抢眼，分章节移动色块又削弱了内页的一致性，因此这两稿都回退到原版。

## 参考与取舍

- 用尺度、对比、平衡和知觉分组解释页内层级。用主张与视觉证据规划页面，再按报告需要把标题缩短，完整结论留在相邻正文或备注。[Nielsen Norman Group](https://www.nngroup.com/articles/principles-visual-design/) · [Penn State 科学演示设计](https://www.writing.engr.psu.edu/teaching_presentations.html)
- 从 Metropolis 借内页的低装饰密度，从 Focus 借常规页与强调页的区分，从 Michaillat 的 16:9 样例借排印和大图空间。中文模板的红白、深绿、蓝白方法归纳为上面的三套颜色角色。[Metropolis](https://github.com/matze/mtheme) · [Focus](https://github.com/pcafrica/focus-beamertheme) · [Michaillat 16:9 样例](https://pascalmichaillat.org/cw.pdf) · [红白开题模板系列](https://www.ppt118.com/ppt/kaitihuibao)
- 图表使用分类、顺序和发散配色。参考网页对比规范筛查文字与背景的配色，投影仍需实看。[ColorBrewer](https://colorbrewer2.org/learnmore/schemes_full.html) · [W3C 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
