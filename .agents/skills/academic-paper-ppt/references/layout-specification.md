# 学术论文讲稿的视觉规范与硬约束

## 使用范围

适用于新制、重排或重新生成论文汇报。用户明确指定模板、色系、页数或局部修改范围时，以其要求为准。只改备注、文字或指定页时，页面设计规范仅用于用户授权修改的部分。

三份参考稿提供三种可复用的能力。《ProteinMPNN》提供原图与解释的对齐方式，《Lean Retrieval》提供长报告的导航和证据提炼，《Beier 个人陈述》提供封面、过渡和证据页之间的视觉节奏。参考页码按原文件实际顺序。详情用于选择下一份讲稿的构图，无需依赖参考文件仍在本机。

## 硬约束

| 项目 | 必须满足 | 怎么验收 |
|---|---|---|
| 讲述结构 | 先定研究问题、章节、关键证据和解释顺序，再制作。第二页为目录，章节名和顺序对应正文。短篇单论文允许合并数据、方法细节和讨论。 | 对照目录逐条找到正文起点，确认章节名和阅读顺序一致。 |
| 章节与页脚 | 章节名、章节编号用来定位。默认省去幻灯片页码、总页数、页码范围及替代进度条。论文的图表编号、公式编号和引用编号照原文保留。 | 缩略图检查导航，并核对首尾页、目录及母版的页号对象。 |
| 底色 | 封面中央图文区和普通正文使用连续白底，白底原图周围也白。大色块优先用于页边、章节切换或一处主题需要，保持阅读区完整。 | 看实际渲染的图边、图注和版心。检查原图周围无灰底接缝或额外底板。 |
| 颜色 | 默认北大红 `#8B0012`、近黑 `#1A1A1A` 和白 `#FFFFFF`。正文及自排图注、脚注、图内标签、表格文字使用深色。浅灰用于分隔及非文字背景。避免粉灰底、低透明度红字和浅灰文字。 | 查看 PPTX 对象的实际颜色并目视渲染。普通小字以 4.5:1 为对比度下限参考。原图图例与数据色保留。 |
| 字体和措辞 | 自排中文使用宋体，英文和拉丁数字使用 Arial，混排分别指定字体。标题、目录及正文写为可独立理解的短语或句子。正式名称和原式保留原写法。 | 检查母版继承、导出替换、续行、标点孤行及用中点串接的片段。 |
| 标题与分点 | 标题写成具体的对象、动作或判断短语。禁止「XX 的读法」「XX 解读」「结果分析」这类元标题；起不出贴切标题时省略标题行，直接排内容。图旁解释组用「短锚点标签＋说明」：锚点取图上的模块名、对象名或对照名（17–18 pt 北大红），说明 1–2 行（15–16 pt），行内含具体要素。纯文字分点写完整短句，不带引导标签。 | 全稿搜索「读法」「解读」类元标题；逐条说明确认不超过 2 行；锚点确实是图上的对象名而非空帽子。 |
| 图注与图幅 | 图注只写原文图号与原文语言（Fig. 2a–b），不翻译、不加解释句。原图在内容区内占主位：单图页图高不小于内容区高度的 60%，图文页图宽不小于版心的 50%，放大到放映可读后保持真实比例。很小的实验结果合并一页，上下排列、左图右文。 | 图注长度不超过一个图号短语；缩略图看图是否为该页最大对象；图内坐标、图例在放映尺寸可读。 |
| 证据 | 主要实验优先使用作者重点解释的原图、原表或原始分面。保留图例、坐标、分母、对照及变异信息。每页注明来源，图与结论能互相定位。 | 放映尺寸逐图检视并回查来源。裁图保留读图所需元素，去除 PDF 外围批注框、邻图残片和四周空白边。 |
| 公式 | 自排公式用 LaTeX 转可编辑 Office Math。少量公式作为对应方法或结果旁的补充。单独公式页限于确有独立讲解价值的情况。 | 在最终文件中数公式对象，在渲染中检查符号、上下标、分式、位置和解释对应。 |
| 版面 | 参照《ProteinMPNN》《Lean Retrieval》的间距节奏：主标题上缘距页顶约 0.8 英寸，内容区约 2.0–5.9 英寸，页脚细线约 6.6 英寸。图与文放在内容区内，与标题区、页脚之间各留 0.3–0.5 英寸以上的呼吸带；页面不为填满而填满。每页正文说明合计不超过 8 行，解释组 2–4 个，组间空白不小于组内行距的两倍。留白集中在页边、组间和页脚上方；一侧大片空白而另一侧拥挤才需要修正。 | 量标题、内容区、页脚三条线的位置与组间距；逐页数正文行数。缩略图看呼吸感，放映尺寸看图和文字。修改后再渲染。 |
| 交付 | 检查的是最终 PPTX 的逐页渲染。组合看板应使用该版本渲染与对应下载文件。 | 回读文件、备注和公式结构，目视每页。看板核对篇数、页数、主题跳转及下载一致性。无法完成的放映验证写入交付说明。 |

## 视觉语言

### 红、黑、白的分工

- 白色承载正文和图证，是覆盖面积最大的底色。图与白色版心连接时，优先用图注、对齐和留白分组。只有确有边界歧义时才加低对比度细线。
- 近黑用于标题和解释。大标题回答本页要讲什么，普通文字说明对象、条件、动作或结果。段落层级主要来自字号、字重和间距。
- 深红先给章节定位和目录编号，再给解释组的短锚点标签、页面最重要的结论或数值。锚点标签是图上对象的名词短语，不是每条文字的例行帽子；纯文字分点仍用近黑完整句，需要强调的词在句内加粗。某页只需要一处强调时，让这一处显眼。红色全页分布应能对应明确的阅读任务。
- 封面可用完整的深红上沿、下沿或边角，在缩略图中明显强于普通内页。过渡页可加大章节号、标题字重或红色面积。短讲通常用同一页眉位置的章节标签完成切换。证据页把红色收回到页眉、图旁标题和关键结果附近。保留原图自身配色。
- 辅助深蓝 `#1F4E79` 适用于同页并列的第二种方法、输入条件或流程分支。先确定每个颜色的含义，再跨页沿用。图中同一对象的已有色彩保留。仅靠颜色难以分辨时，加直接标签或线型。

### 页眉、版心与来源位置

以 16:9、约 13.33 × 7.5 英寸版面为基准，横向左右各约 5% 页宽起版心，竖向全稿按同一节奏排。以下是《ProteinMPNN》与《Lean Retrieval》两份参考稿的实测值，按它起排：

| 元素 | 距页顶 | 字号 | 说明 |
|---|---|---|---|
| 章节标签 | 约 0.45 英寸 | 12–13 pt | 北大红粗体，可配一小段红标记 |
| 主标题 | 约 0.8 英寸 | 28–32 pt | 一行短语或短判断，粗体 |
| 条件行 | 约 1.4–1.5 英寸 | 14–16 pt | 一行对象或评测条件，可省 |
| 内容区 | 约 2.0–5.9 英寸 | — | 图与解释组都在此区间内 |
| 图注 | 图下贴图 | 12–13 pt | 只写原文图号 |
| 转场问题（可选） | 约 6.4 英寸 | 14–15 pt | 一行红色问句，承接下一页 |
| 来源脚注 | 约 6.9 英寸 | 11–11.5 pt | 与页脚细线同基线 |

- 图与文的上下都留呼吸带：内容区上缘距标题区（含条件行）0.3 英寸以上，下缘距页脚细线 0.5 英寸以上。图在内容区内占主位、按真实比例放大，但不为填满而贴线。留白集中在页边、组间和页脚上方，这是参考稿呼吸感的主要来源。
- 解释组的标准形态是「短锚点标签＋1–2 行说明」：标签取图上的模块名、对象名或对照名，17–18 pt 北大红；说明 15–16 pt，一到两行，行距约 1.3，每条带一个具体要素。组与组之间留 0.4–0.6 英寸空白，不小于组内行距的两倍。一页通常 2–4 组，正文说明合计不超过 8 行。
- 同级元素全稿同字号、同位置：标题左线、章节标签、图注和脚注沿同一左线，页脚位置稳定。内容结构随证据改变，全稿无需每页同样的图幅或同样的组数。
- 若一行主标题已能说清判断，条件行可省。来源置于左下共同基线，图注贴图、只写原文图号（如 `Fig. 2a–b`），脚注负责出处与改动说明。
- 窄栏先缩短句子或加宽版面。字号是试排起点，实际渲染能否读清优先；放映读不清时先裁图或删字，不放字号。
- 用缩略图判断视觉重量，用单页判断字与图的可读性。把图证整体和解释整体作为两个对象配平。目录或理论过渡的留白可以保留，它承担层次和停顿。主要结果页的失衡通常表现为一侧小图或短字孤立、另一侧文字堆叠，应调整对象尺寸与位置。

## 页面选择与构图

下表给出的列宽是正文可用宽度的比例，可随原图和标题调整。优先挑满足读图条件的构图，再用余下空间安置解释。

| 页型 | 构图和阅读顺序 | 什么时候换一种 |
|---|---|---|
| 封面 | 题名和一个可核查主视觉共享白底。主标题、论文信息、作者或汇报信息分层。沿侧边或水平边缘布置深红。 | 宽图占比过大时，可在标题下方居中放图。高图更适合图文左右，按图的真实比例分配区域。 |
| 第二页目录 | 条目少（3–4 项）且名称短时用编号网格：大号红色编号配短章节名，4 项两列两行，3 项一行三列或上二下一，参考《Beier 个人陈述》第 2 页。较长标题用单列。主题多的多论文分栏。 | 条目下不写小标题或阐述行，标题下也不写总述句。标题挤成多行时先简化名称。 |
| 章节过渡 | 长讲的明显切换处放章节题名和一句具体问题，编号和题名照目录。可用比证据页更明显的深红特色。 | 短讲在正文页眉复用章节名即可，节省放映页和口播时间。 |
| 原图配讲解 | 约 55%–65% 放原图，35%–45% 放解释组。解释组用「短锚点＋1–2 行说明」按图读序从上到下排，组间留白；锚点取图上的模块名或面板号。 | 多列或横向流程读不清时改成跨版心图，图下分段解释。 |
| 宽流程或宽结果图 | 主图跨版心放大，上下留呼吸带。图下按流程或分面排两三个解释块，读序与图一致，块间留白不小于块高。 | 如果图内已有清晰的过程说明，留一两条直接结论即可。 |
| 可比较的并列证据 | 两图共享可比条件时同屏对齐。先看列标题，再看图，最后看对应结论。成对项目用同一图幅、轴标尺度或对照位置，必要时用红蓝区分。 | 两图口径不同就写出条件差异。图表需要不同宽度或结论不构成直接对照时，用上下或主次版式。 |
| 原表与结果提炼 | 主表占约三分之二或更多版心，旁边给一句关键比较或一个数字对照，样本和统计口径贴近原表。 | 表过宽时让表跨版心，结果句放下方。保留比较所需列和原表出处。 |
| 小结果合页 | 同一板块的 2–3 个很小的实验结果合并一页，上下排列，每行左图右文，图约占行宽 50%–60%，右侧各配 1–2 个短解释组，行间以组距或细线分隔。 | 左栏图例太小时拆页，或裁取与主张相关且信息完整的分面。两结果间无明确关系时分开讲。 |
| 方法或结果旁的补充公式 | 图文保留主位，公式放在邻侧。解释紧跟对应式子。一个关键指标的公式和主结果可在同一侧分成上下两组。 | 一条短式也可以置于正文相邻处。多行推导确需独立讲解时，公式在左，解释按行在右。 |
| 观察与开放问题 | 用位置区分已有数据和待检验解释。图中观察和右栏问题通过对应对象连接，并在讲述中交代证据层级。 | 单条局限贴在结果旁或放入备注。章节末独立讨论需能回答一个重要问题。 |

## 参考稿的具体做法与移植尺度

- 《ProteinMPNN》第 3 页。左侧完整架构图，右侧按骨架特征、图编码和解码分段，关键对照单独显示。移植时把解释标题写成图上的模块，用短句说清每一步。样本与基线写在数字附近。适合首个方法页或一页解释一项明确结果。
- 《ProteinMPNN》第 15 页。宽图的对照在上，解释沿图的阅读顺序在下。移植时先保证图中的路径和图例能读清，再放下方解释。对于横向流程，保持左到右的读序可直接改善观看体验。
- 《Lean Retrieval》第 2 页及第 3、7、17、31、38 页。目录的章节号和题名与各节切换页对应。移植时采用目录的定位逻辑，给短讲的正文加简短章节名，长讲再使用独立过渡页。
- 《Lean Retrieval》第 6、41 页。第 6 页用色区分并列接口，第 41 页把完整证据与关键对照分开放。移植时先保留原始对照的可核查信息，再把一个最值得记住的结果提到旁边。配色跟随方法或分支的真实角色。
- 《Beier 个人陈述》第 2、6–9、12 页。第 2 页让四项短章节共用两列。项目过渡页的红色面积显著增加，证据页回到白底。第 8–9 页把分面与解读对应，第 12 页用不同区域承载观察和开放问题。移植时保留图文对位和轻重节奏。根据实际报告的素材选择主视觉，文字区可依靠组间留白及短标题。
- 间距节奏以《ProteinMPNN》第 3、4、7、12 页和《Lean Retrieval》第 4、6、10 页为量度：主标题上缘距页顶约 0.8 英寸，内容区约在页高的 27%–78% 之间，脚注在 93%–95%；正文 15–16 pt，锚点 17–20 pt，图注 12–13 pt；解释组 2–4 个、每组至多两行，组距约为组高的两倍。页面的呼吸感来自这些空白带，不来自缩小图或压行距。
- 批量重排时，先为正文比较有代表性的三种页面。通常选原图配讲解的方法页、最密集的结果页、一个有图与证据边界的页面。以实际渲染进行改前、改后的对照，确认图幅、解释位置或阅读顺序出现有意义的改善，再扩展到其余页面。只调整页眉、编号和目录无法完成正文版式重排。

## 交付前逐页复核

1. 封面和目录分别确认第一眼焦点、红色与白底的关系、章节读序。随后按目录走一遍正文，章节定位不能跳号或混用别名。
2. 方法页从图里的第一个输入开始试讲，逐项找到右栏或图下对应说明。确认标题、图、文字的起点和组间空隙给出了同一条读序。
3. 结果页先找到主对照和关键变量，再读结果句。核对图表和说明的样本、分母、单位和比较对象，确认重要结论贴着证据且读者能核算。开放问题和工作假设的位置应能辨识。
4. 在所有页面的实际渲染中查看重心、对齐、行距、颜色对比、图注位置、页脚裁切和继承字体。明显过密时优先删重复句、裁取有用面板或拆页。右侧大片空白而左侧密集时，试把按图顺序的讲解移到右侧。左右栏的图文没有对应关系时，改为上下结构。
5. 改完重新渲染。逐页核对备注和对应证据，公式同时检查可编辑对象和视觉渲染。看板从本次最终 PPTX 生成，主题跳转应按每篇的语义定位。
