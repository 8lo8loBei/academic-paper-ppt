# 版面规格与硬指标

本文件是全稿几何、字号、密度和图幅的唯一事实来源。其他文件只解释怎么用，不另立数值。参考值实测自《Lean Retrieval》《ProteinMPNN》两份参考稿，并按放映可读性上调。

## 画布与三带

16:9 画布 13.333 × 7.5 英寸。版心左右各留 0.67 英寸，可用宽 12.0 英寸。每个内页按三条水平线组织，全稿不跳线：

| 带 | 纵向范围 | 放什么 |
|---|---|---|
| 页眉带 | 0–1.5 英寸 | 章节标签、主标题、条件行 |
| 内容带 | 1.95–6.40 英寸 | 图、表、公式、分点 |
| 页脚带 | 6.62–7.20 英寸 | 页脚细线、来源脚注 |

页底 7.20 英寸以下不放任何对象。

## 字号阶梯

同一层级全稿同字号，不按页面单独调。

| 元素 | 字号 | 字重与颜色 | 说明 |
|---|---|---|---|
| 章节标签 | 13 pt | 北大红粗体 | 一行，可配短红标记 |
| 主标题 | 32 pt | 近黑粗体 | 一行；确需两行降到 28 pt |
| 条件行 / 英文原题 | 16 pt | 近黑常规 | 一行，可省 |
| 分点正文（图旁、图下、纯文字页同级） | 17 pt | 近黑常规 | 完整短句，每条 1–2 行，无前置标签 |
| 关键数字 | 21–24 pt | 北大红粗体 | 一页至多一处 |
| 图注 | 13 pt | 近黑常规 | 只写原文图号 |
| 表头 | 13–14 pt | 白字配深红底 | 与表体同一字体 |
| 表体 | 12–13 pt | 近黑常规 | 行高 ≥0.40 英寸 |
| 公式（独立） | 20–24 pt | Cambria Math | 不低于 18 pt |
| 公式（行内） | 与正文同 | Cambria Math | 不单独缩小 |
| 页脚来源 | 12 pt | 近黑常规 | 不低于 12 pt |
| 参考文献 | 13 pt | 近黑常规 | 行距 1.25 |
| 封面主标题 | 42–68 pt | 北大红粗体 | 见 cover-and-visuals |
| 封面副题 | 24–30 pt | 近黑 | 两行以内 |
| 封面上/下信息 | 12–19 pt | 红或近黑 | kicker 16、汇报人 19、日期 13.5 |

正文任何情况下不低于 17 pt，页脚不低于 12 pt。塞不下时删内容、拆页或裁图，不缩字号、不压行距。

## 密度与留白（内容页逐页达标）

留白只允许出现在页边、组间和页脚上方。判定用可量的边界，不靠感觉：

| 指标 | 下限 / 上限 | 不达标怎么改 |
|---|---|---|
| 内容上沿 | ≤ 2.10 英寸 | 条件行压到 1.45，或删条件行，内容上探 1.75 |
| 含图页内容下沿（含图注） | ≥ 5.90 英寸 | 放大图；图注上贴；不够就换更大的主图 |
| 纯文字页正文下沿 | ≥ 5.20 英寸 | 补一条证据、与相邻页合并，或把字号/行距用足 |
| 内容横向跨度 | ≥ 9.5 英寸 | 图跨版心，或把右侧短句移到右侧栏 |
| 页内空白矩形 | 不得出现 >1.2 × 1.2 英寸的无对象区域（组间 0.45–0.6 英寸除外） | 放大主证据、调整列宽或合并页 |
| 正文总行数 | ≤ 8 行 | 移备注或拆页 |
| 分点条数 | 2–4 条，每条 1–2 行 | 单条内容页说明内容太薄，合并 |
| 组间距 | 0.45–0.6 英寸（≥ 行距两倍） | 拉开组距，不要拉开字距 |
| 标题到内容 | 0.25–0.45 英寸 | 内容整体上移 |
| 内容到页脚线 | ≥ 0.20 英寸 | 内容整体上收或裁图 |

页面上只有一两行字时，先判断它是否值得单独一页：能回答一个独立问题的保留（如目录、章节过渡），否则并入相邻页或做成「小结果合页」。全稿内容页的平均正文行数应落在 4–7 行之间；连续三页低于 3 行视为密度不足。

## 图幅占比（按墨迹边界量）

「图幅」指裁掉白边后的实际内容区域，不是图片框。PDF 抽出的图先按 ink bbox（任一通道 < 248 的像素范围）紧裁到内容 + 4 px 再入库；否则按框达标、实际可见内容只有一半。

| 页型 | 图宽 | 图高 | 面积占整页 |
|---|---|---|---|
| 单图证据页 | ≥ 9.5 英寸 | ≥ 3.6 英寸 | ≥ 32% |
| 图文并列 | ≥ 6.0 英寸 | ≥ 3.4 英寸 | ≥ 25% |
| 双图对照 | 每幅 ≥ 4.8 英寸 | 每幅 ≥ 3.4 英寸 | 每幅 ≥ 18% |
| 小结果合页（每行） | 6.0–7.2 英寸 | ≥ 1.5 英寸 | 每行 ≥ 9% |
| 封面主图 | ≥ 3.4 英寸 | ≥ 3.4 英寸 | ≥ 15% |
| 表格（代替图） | 全宽 ≥ 9.0 或旁栏 ≥ 7.0 英寸 | ≥ 3.0 英寸 | ≥ 30% |

图必须是该页面积最大的单个对象。达不到阈值时按顺序处理：裁掉与主张无关的面板 → 换更贴近主张的原图 → 拆页。不要用加边框、加底色或放大留白来假装占满。

## 页型与坐标

每个页型的槽位坐标见 [页面配方](page-recipes.md)。选页型前先看主图比例：横宽图用单图页或上图下文，竖图用图文并列，成对同口径图用双图对照，2–3 个很小的结果用合页。

## 反模式清单（看到就改）

| 现象 | 改法 |
|---|---|
| 标题距顶 >1.0 英寸，或内容上沿 >2.2 英寸 | 上移到三带位置 |
| 一页只有 1–2 条短句，且无图 | 与相邻页合并，或补主图/表 |
| 图在框里居中、四周白边明显 | 紧裁墨迹后按高度重放 |
| 图只占版心一半，右侧成片空白 | 图跨版心，或把解释移到右侧 |
| 三块以上「小标题＋一行解释」 | 合并成 2–4 条无标签分点 |
| 正文低于 17 pt | 提到 17 pt，删句腾位置 |
| 图注写成中文解释句 | 只留 `Fig. 2a–b` |
| 同页两处以上红色强调 | 只留一处，其余改近黑加粗 |
| 「XX 的读法」「结果分析」「小结」作标题 | 换成具体判断；起不出就省略标题行 |
| 分点前加「输入：」「作用：」标签 | 删掉标签，把模块名、面板号写进句子 |
| 公式是图片、文本框或 Unicode 拼的 | 改为 OMML 公式对象 |
| 公式页正文不足内容带一半 | 公式与解释按配方填满，或并回方法页 |
| 封面顶部只有装饰条、底部空荡 | 顶部放 kicker/细线，底部放汇报人、日期、图源 |
| 末页只有「Thank you」 | 改为总结页或参考文献页 |
| 页脚出现页码、总页数、进度编号 | 全部删除，保留来源与图表编号 |

## 怎么量

- 位置与尺寸：用 python-pptx 读 `shape.left/top/width/height`，除以 914400 得英寸；组内对象需遍历 `shape.shapes`。
- 图墨迹：用 PIL 或 numpy 扫描非白像素，取 bbox；与页面面积比即「墨迹占比」。
- 密度：先算内容带内所有可见对象的并集 bbox，再对照上表；空洞用并集 bbox 减去对象面积估算，只用于发现明显问题。
- 最终以放映渲染为准：PPTX 转 PDF 后逐页转图，按上面数值复核，不只看 XML。

`scripts/audit_deck.py` 可自动检查画布比例、每页备注、页码文字、图片占比、最小字号和 OMML 公式数量；它只做机器可判的部分，视觉判断仍按 [验收清单](review-requirements.md) 逐页看渲染。
