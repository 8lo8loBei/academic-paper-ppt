# 验收清单

按顺序执行。每一步都对照数值，不用「看起来还行」作结论。硬指标来自 [版面规格](layout-specification.md)，本文件只负责怎么查、查不过怎么办。

## 第 0 步：开工前

- [ ] 明确时长、听众、篇数、指定模板、不能改的部分；缺失时按 8–12 分钟单篇起稿并在交付说明中写明假设。
- [ ] 写下最短论证链：已有方法能做什么 → 什么问题卡着 → 论文改了哪一步 → 什么证据支持。
- [ ] 生成页面清单：每页一行，列「听众要懂什么 / 证据 / 口播要点 / 出处」。
- [ ] 确认末页安排：总结页、参考文献页，或两者合并。

## 第 1 步：内容验收（先于排版）

- [ ] 每页有一句可核验的判断，标题或主结论说得出这句话。
- [ ] 每条上屏文字至少带一个具体要素：数值与口径、对象名、条件、机制动作。名词解释式、标题复述式、只有形容词的条目全部返工。
- [ ] 每个数字回查原文：指标、单位、数据集/子集、分母、基线、方向、出处。
- [ ] 方法页每模块写清输入 → 动作 → 输出；结果页写清对照、差值方向、口径和边界。
- [ ] 旁支、推导、次要参数在备注或附录，不在正文堆叠。
- [ ] 只有 1–2 行字的内容页已合并，或确有独立讲解价值。

## 第 2 步：版面验收（逐页量）

用 python-pptx 读坐标，换算成英寸后对照下表；同时保留最终渲染图用于目视复核。

| 检查项 | 通过标准 | 不通过时 |
|---|---|---|
| 画布 | 13.333 × 7.5 英寸 | 重设页面 |
| 内容上沿 | ≤2.10 | 上移内容或删条件行 |
| 含图页下沿（含图注） | ≥5.90 | 放大图、上贴图注 |
| 纯文字页下沿 | ≥5.20 | 补证据或合页 |
| 内容横向跨度 | ≥9.5 | 图跨版心 / 调整列宽 |
| 空白矩形 | 无 >1.2 × 1.2 英寸的空洞（组间 0.45–0.6 除外） | 放大主证据、合并页 |
| 正文行数 | ≤8 | 移备注或拆页 |
| 分点条数 | 2–4 | 合并或补图 |
| 图占页面积 | 单图 ≥32%，图文 ≥25%，双图各 ≥18%，合页每行 ≥9% | 裁面板、换图、拆页 |
| 图是否为最大对象 | 是 | 缩小文字或放大图 |
| 字号 | 标题 32；分点 17；图注 13；脚注 12；正文 ≥17 | 改字号阶梯，删内容腾位置 |
| 分点标签 | 无小标题、锚点或加粗引导词 | 标签写进句内 |
| 图注 | 只有 `Fig. X` 类图号 | 删解释句 |
| 页脚 | 无页码、总页数、进度编号 | 删除母版与手写对象 |
| 对齐 | 标题、图注、脚注同一左线；同级同字号 | 统一锚点 |

## 第 3 步：封面、目录、末页

- [ ] 封面顶带有 kicker 或校徽 + 细线；底带有汇报人、日期、机构/图源；页底 0.3 英寸内无对象。
- [ ] 主标题 42–68 pt 红色；副题 24–30 pt；第一眼看到标题而不是装饰。
- [ ] 主图占页 ≥15%，白底与版心衔接，无阴影/底板。
- [ ] 目录 3–8 项，条目名具体（不是「研究背景/方法介绍」式通用词），与正文同名同序；无描述行、无页码范围。
- [ ] 单列/双列坐标按配方执行，最长条目能放下。
- [ ] 末页是总结或参考文献；无单独 `Thank you` 页；多篇分享末页为参考文献。
- [ ] 参考文献条目与正文脚注编号一致，字段完整（作者、题名、出处、年份、DOI/arXiv）。

## 第 4 步：公式

- [ ] 每个自行排版的公式都是可编辑 Office Math；PPTX 中存在 `m:oMath`/`m:oMathPara`，数量与页面公式数一致。
- [ ] 最终渲染中逐式核对符号、上下标、分式、括号、求和上下限、正负号、对齐；无裁切、无重叠。
- [ ] 每个公式有三层解释：算什么、符号逐个、方向与作用；解释与公式首行对齐。
- [ ] 独立公式 ≥18 pt；一页 ≤3 式；公式列与解释列平衡，不留下半页空白。
- [ ] 正文引用公式的编号与页面式号一致。

## 第 5 步：备注

- [ ] 每页都有备注；没有空备注页。
- [ ] 按四段结构：本页问题、按视线指图、结论边界、过渡；复杂页有备答与出处。
- [ ] 每页 40–200 字，按页型落在 [长度表](speaker-notes.md#长度与节奏) 区间；通读计时符合总时长。
- [ ] 数字带口径，术语首次解释，无「见上页」「效果很好」。
- [ ] 备注与页面术语、数字、图号一致；只改备注时页面渲染不变。

## 第 6 步：渲染与目视

- [ ] 最终 PPTX 转 PDF，逐页转图，按放映尺寸看（不低于 1600 px 宽）。
- [ ] 检查视觉重心：一侧大片空白、另一侧拥挤 → 调整图幅或列宽后重渲染。
- [ ] 检查图、表、公式的裁切、遮挡、模糊、字体替换；中英文与字体属性正确。
- [ ] 检查标点孤行、单字孤行、同级字号、换行位置。
- [ ] 回到缩略图通看：封面、目录、正文、过渡、末页是同一套模板；相邻页标题与页脚不跳动。

## 第 7 步：交付

- [ ] 导出文件可打开，正文、图片、表格、公式、备注可编辑。
- [ ] 保存路径与文件名清楚；交付说明写清页数、时长、仍存在的缺项（如无法核验的公式页）。
- [ ] 定向改稿：给出改前/改后同页对照，确认用户要求保留的部分未动。
- [ ] 页数变化时同步三处：页面清单、渲染目录里的旧逐页图、看板/目录的计数断言。

## 工程教训（渲染管线）

1. 图幅问题先查素材：PDF 抽图常带白边，紧裁后再量；不要先怀疑版式或渲染器。
2. 「最终渲染」指最终 PPTX 的放映渲染；XML 检查通过不等于视觉通过。公式、分点、图片填充都要在渲染上复核。
3. 质量门禁按序执行且逐步检查退出码：生成 → 定稿（字体/公式/表格/图片）→ 转 PDF → 逐页渲染 → 拼版/看板 → 冒烟测试。不用管道吞掉前序报错。
4. 内容密度与版面密度分开查：内容看每条是否带可核查要素；版面看行数、字号、留白。塞不下时拆页或移备注。
5. 批量/长时任务保留逐页日志与中间产物；改稿后清掉渲染目录中多余的旧页图，避免旧版混入。
