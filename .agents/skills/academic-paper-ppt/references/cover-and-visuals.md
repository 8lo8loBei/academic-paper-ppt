# 封面、配色与图表版式

## 主动完成封面

1. 先确定标题任务。学术分享可以用原题或广为辨识的论文名作主标题，用一句副标题讲清本次汇报的切口。核对副标题准确性，把作者、机构、会议、汇报人分到明确层级。用用户实际指定的身份信息，省去重复或无用的关键词、学院和日期。
2. 查看论文正文、图注和项目页，先选一个有辨识度的原论文对象、结构、装置、图像或定性结果。试两种取景或构图，例如左侧主副标题加右侧大图，或者居中标题配有留白的横向证据图。按可识别性、留白、裁切和图源可核验性选一个完成，通常无需把选择留给用户。
3. 封面图优先用用户素材或可核验的论文原图与项目素材。搜索外部素材时记录出处和许可信息。需要生成视觉时，给图像工具可见对象、构图位置、留白、背景和色温，要求省去文字、数据和随机界面元素。把生成图限定为概念插图或气氛配图，在需要区分时标注示意。实验图、真实分子结构、定量结果和读数以论文证据为准。
4. 最后检查第一眼先看到标题还是装饰，主副标题是否显著分层，汇报人是否靠近标题区，主图是否被挤成小缩略图。主图出处放在图下或备注中，避免把整页塞满名词、作者名单和装饰条。

## 自适应配色与排版

- 有用户模板或品牌时跟随。其余情况从主图或研究对象提取一到两个候选强调色，再配中性主背景和高对比正文。按用途锁定背景、正文、强调、线条、基线和主要方法的色值。统一同一个模型在各页的颜色，表格用文字或线式辅助识别。
- 安静的默认方向可用白色或暖白背景、深黑正文和单一强调色。ProteinMPNN 分享中的白底红黑是一个案例。其他题材可以用深蓝、墨绿或原图取色。只有确有需要时再加入第二个强调色。
- 少用渐变、霓虹、光晕、芯片纹、悬浮卡片、每一项一个图标、玻璃拟态或厚阴影。用留白、字号、细分隔线、图片比例和节奏建立高级感。字体一致，中文与拉丁字母匹配，避免把脚注压缩到现场读不清。
- 保持版心、基线、页脚、图注和编号一致。页面可读性差时先减字、裁进有效图域或拆成两页。小图密表看不清时提取有结论的单个 panel，完整图进附录。

## 版式随内容改变

| 页面任务 | 优先构图 | 着重检查 |
|---|---|---|
| 问题和背景 | 一句科学问题配一张占主视觉的对象图、示意图或可比较的场景 | 两者关系直观，图有清楚标签 |
| 主要流程 | 横向步骤、纵向分层或泳道，按真实拓扑选择 | 箭头有确切含义，训练/推理、候选/筛选各自有位置 |
| 主方法 | 论文主图为主，旁边注释关键节点。公式页用一个短公式配对应变量及变化方向 | 先说明输入和输出，再讲变量。图中符号与备注一致 |
| 原图结果 | 左图右结论或大图上、读法下，只保留核心 panel | 坐标、图例、误差、分母和来源可读。强调色用在要讲的数据上 |
| 多方法对比 | 比较维度少、方法适中时用表或小多图，强调对照列 | 统一名词和口径，避免把不同角色的使用算在一个类别里 |
| Discussion | 两到三组已验证证据和仍待回答的问题，靠对齐与细线分隔 | 每个局限对应一项具体实验或假设 |
| 总结 | 三项可复述的结论。主题综述可用小型关系图或用户已有导图 | 屏幕上能读清，范围扩展图可移入附录 |

## 图像和导出

- 原图保留必要标签和数据。重绘时逐项核原值，标出重绘、单位、图号及误差定义。不可读的曲线不要从截图估值。方法示意允许简化画法，但不改模型开关、处理对象或箭头方向。
- 用真实资产时在页脚或图注放短出处，在备注放可点击全源。只为讲解加数字、圈线、引导词时，尽量使用可编辑对象。
- 用户要求 SVG → HTML → PPT 时，先看 SVG 图形和叙事顺序，再核对 HTML 与 PPT 导出中的版式和文字。其他情况下用最少转换保留可编辑性。
- 全稿缩略图检查风格、页型节奏与对齐。放映尺寸检查封面、机制图、结果页和数据表，确认无裁切、遮挡、过密、破碎换行和字体替换。验收渲染结果，即使工具报告通过也要看实际页面。
