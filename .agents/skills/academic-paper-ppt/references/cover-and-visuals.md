# 封面、配色与图表版式

## 主动完成封面

1. 先确定标题任务。学术分享可以用原题或广为辨识的论文名作主标题，用一句副标题讲清本次汇报的切口。核对副标题准确性，把作者、机构、会议、汇报人分到明确层级。用用户实际指定的身份信息，省去重复或无用的关键词、学院和日期。
2. 查看论文正文、图注和项目页，先选一个有辨识度的原论文对象、结构、装置、图像或定性结果。试两种取景或构图，例如左侧主副标题加右侧大图，或者居中标题配有留白的横向证据图。按可识别性、留白、裁切和图源可核验性选一个完成，通常无需把选择留给用户。
3. 封面中央标题、作者和论文原图所在的版心统一用白色背景。用北大红的边缘色带、边角几何或标题强调提升主题色分量，保留原图和标题的视觉主位。检查白底原图与周围版心能自然衔接。
4. 封面图优先用用户素材或可核验的论文原图与项目素材。搜索外部素材时记录出处和许可信息。需要生成视觉时，给图像工具可见对象、构图位置、留白、背景和色温，要求省去文字、数据和随机界面元素。把生成图限定为概念插图或气氛配图，在需要区分时标注示意。实验图、真实分子结构、定量结果和读数以论文证据为准。
4. 最后检查第一眼先看到标题还是装饰，主副标题是否显著分层，汇报人是否靠近标题区，主图是否被挤成小缩略图。主图出处放在图下或备注中，避免把整页塞满名词、作者名单和装饰条。

## 先规划画面

- 先为每页安排标题、主证据、讲解和脚注，再把内容放进画面。主图页先根据原图比例定图幅，原图按放映可读的最大尺寸放：单图页图高不小于内容区七成，图文页图宽不小于版心 55%，上缘贴住标题区、下缘贴住底部细线。文字页先定单栏版心或纵向分组。按图表大小和文本长度分配空间，减少卡片式留白、过宽列距和大块空白，标题与底部细线之间不留大片空白。
- 内容页标题优先是一行短语、简短问句或简洁判断。优先保留研究对象与本页切口。不写「XX 的读法」「XX 解读」这类元标题，起不出贴切标题就省略标题行直接写内容。条件、方法限定和解释移到正文或备注。封面可保留论文原题。
- 普通文字页用单栏左对齐。横向主图用上图下文，窄图可配一组侧栏短分点。两组文字并排时，用明确的对照维度对齐内容。很小的实验结果按上下两行合并一页，每行左图右文。

## 配色和文字排版

全稿色值、背景母版与图表用色按 [学术汇报设计体系](design-system.md#按角色分配颜色) 规划。

- 自行排版的标题、副标题、正文、表格、图表标签、图注、脚注、页脚、参考文献和备注中的中文一律用宋体（SimSun）。英文和拉丁数字统一用 Arial。中英混排分别指定东亚字体和拉丁字体，避免依赖主题的默认替换。论文原图保留原有字形，公式沿用 Office Math 的数学字体。
- 普通文字框保持无填充、无边框。短标题、标签、单个数字和一句结论贴近对应内容摆放，避免给它们单独划出大块方框、卡片或有底色的图注。
- 正文用短分点，项目符号和正文分别沿各自的左边线，续行与首行正文对齐。并列标题和首条正文沿同一基线。同级分点之间留一致的间距，让图注靠近图。
- 用标题字号、段间距和浅灰细线分层。同级正文和表格数据保持统一字号，句中重点词语或数字可以在原位加粗、斜体。完整句子写在同一段或同一条分点中，允许自然换行。表格用于确有行列对应关系的数值、指标和类别，禁止把一条完整句子切成若干单元格或为同一句的片段任意改字号。
- 论文原图和承担数据编码的图表保留自身结构。自绘流程图中确实表示动作或对象的节点可以用紧凑轮廓；箭头、位置关系和数据标记表达含义。普通讲解文字和摘要保持无底色。

## 版式随内容改变

| 页面任务 | 优先构图 | 着重检查 |
|---|---|---|
| 问题和背景 | 短标题配一张对象图或示意图，补充文字在图下单栏左对齐 | 仅有明确的两项对照且文字很短时用双栏 |
| 主要流程 | 横向步骤、纵向分层或泳道，按真实拓扑选择 | 箭头有确切含义，训练/推理、候选/筛选各自有位置 |
| 主方法 | 论文主图优先。复杂图独页放大，关键节点说明写进句子。公式居左，变量释义及变化方向居右，按各组公式对齐 | 先说明输入和输出，再讲变量。图中符号与备注一致 |
| 原图结果 | 原图放大居上或居左，上缘贴标题、下缘贴底部细线；结论紧凑放在图下或图旁。复杂结果可独占一页；很小的结果两三个合页，上下排列、左图右文 | 保留支持结论的分面，确保坐标、图例、误差、分母及脚注可读 |
| 多方法对比 | 比较维度少、方法适中时用表或小多图，强调对照列 | 统一名词和口径，避免把不同角色的使用算在一个类别里 |
| Discussion | 两到三组已验证证据和仍待回答的问题，靠对齐与细线分隔 | 每个局限对应一项具体实验或假设 |
| 总结 | 三项可复述的结论。主题综述可用小型关系图或用户已有导图 | 屏幕上能读清，范围扩展图可移入附录 |

## 公式插入与目视检查

1. 从论文原式或清楚标注的讲解推导写出 LaTeX。将等式、不等式、能量差、行内公式和带上下标的变量表达式作为公式处理。
2. 在 PowerPoint 的公式对象中用 LaTeX 输入并转换为排版后的公式。程序化生成时，将同一段 LaTeX 转为 Office Math（OMML）原生公式对象，再嵌入 PPTX。公式可随内容紧凑排版，普通文本框、Unicode 拼式、裸露的 LaTeX 源码、图片、SVG 和矢量轮廓均不得代替公式对象。嵌入的论文原图可保留图内自带标注。凡在 PPT 中单独重排或讲解的公式，一律重新插入为公式对象。
3. 少量公式先放入对应的方法、指标或结果页，在一侧与图表或正文配合，并就近给出变量和读法。若公式本身需要独立讲解，先试左公式、右解释，两侧以首行或组内视觉中心对齐。多条公式按行组织，每条配对应的变量、单位、含义或读法。按公式真实宽度分配列宽和列间距。公式过宽时横跨版心或拆页，优先保留可读字号。
4. 导出后打开最终 PPTX，或将它的公式页渲染成放映尺寸图片并实际查看。把每条渲染公式与原论文或已核对的 LaTeX 逐条对照，检查符号、正负号、括号、上下标、分式、求和上下限和多行对齐。再看基线、间距、裁切及与相邻文字的位置。公式内容错、看不清或被遮挡时，修改后重新导出和目视检查。
5. 在 PowerPoint 中确认公式进入编辑模式，或检查 PPTX 中对应的 Office Math 元素（例如 `m:oMath`、`m:oMathPara`）。结构检查和渲染检查均须完成。原生公式存在、解析无报错、HTML 或 SVG 预览正常，都只能证明对应的单项检查通过。遇到导出丢失公式或无法核验最终渲染，换用能保留并检视原生公式的导出方式。有未验证的公式时，在交付说明中标明具体页码。

## 图像和导出

- 优先引用论文的方法原图、实验结果图及必要的原始表格。复杂多分面图可以独占一页，按比例放到标题和脚注之间的最大可读尺寸；原图尽量放大贴住标题与底部细线，不留大片空白。读图步骤、次要解释和完整推导可写在备注，正文保留必要标注或一句结论。
- 图注只写原文图号与原文语言（如 `Fig. 2a–b`、`Fig. S1a–c`，跟随论文写法），不翻译成中文、不加解释句。
- 保留必要的坐标、单位、图例、误差和原分面编号。确需重绘时逐项核对原值，标明「根据原文重绘」并保留必要的单位和误差定义。引用图表、数据或结论时在当页放可读的短来源脚注，按 [图表来源与参考文献](content-and-evidence.md#图表来源与参考文献) 编号与核对。只为讲解加数字、圈线和引导词时，优先用可编辑对象。
- 用户要求 SVG → HTML → PPT 时，先看 SVG 图形和叙事顺序，再核对 HTML 与 PPT 导出中的版式和文字。其他情况下用最少转换保留可编辑性。

## 放映验收

1. 用缩略图逐页检查标题长度、主体面积和阅读顺序。收紧空白过多的页面，缩短长句标题，拆开并排的长段，删去短语外的大框和重复色带。把富余空间让给主证据或增大图表至可读尺寸。改整套背景时再按 [全稿校验](design-system.md#全稿校验) 核对共用锚点和背景重量。
2. 用放映尺寸检查分点的左边线、续行缩进和同级字号。发现拆句入表或同一句内随意换字号时，改回完整句子并用字重或斜体强调。核对中文是否使用宋体、原图脚注是否可读，以及多篇论文分享是否以完整的参考文献页收尾。
3. 用视觉能力逐张查看最终 PPTX 的实际渲染。检查左右和上下的视觉重量，发现一侧大片空白、另一侧过密时，调整图幅、列宽、行距或整组位置，再重新渲染检查。也检查裁切、遮挡、破碎换行和字体替换。
